
#  NIRVAN '26 — Technical Fest Website

 *Innovate. Compete. Create.*

A modern and responsive website designed for *NIRVAN '26*, a college technical fest. The website provides participants with a simple platform to explore technical events, view the fest schedule, learn about speakers and guests, and register for events.
## 📌 Project Overview

NIRVAN '26 is a college technical fest website developed with a focus on:

* Simple and clear navigation
* Responsive design
* Event information
* Fest schedule
* Speaker and guest information
* Registration system
* User-friendly interface

## ✨ Features

### 🏠 Home

* NIRVAN '26 branding
* Fest information
* Date and venue
* Call-to-action buttons

### 🎯 Event Arena

Participants can explore different technical and non-technical events, such as:

* Hackathon
* Capture The Flag (CTF)
* E-Sports
* Treasure Hunt
* Workshops

Event information includes:

* Event name
* Date and time
* Venue
* Eligibility
* Team size
* Registration fee
* Prize information
* Rules
* Registration option

### 📅 Schedule

The website provides an organized schedule containing:

* Event timings
* Event dates
* Venues
* Day-wise information

### 🎤 Speakers & Guests

The website includes information about invited speakers and guests associated with the technical fest.

### 📝 Registration

Participants can register for events using the registration form.

Registration details include:

* Name
* Email
* Phone number
* College
* Selected event
* Team size

The registration system is being connected with a backend and database.

### 📱 Responsive Design

The website is designed to work on:

* Desktop
* Laptop
* Tablet
* Mobile devices
